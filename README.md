# stm32-ai-projects

基于正点原子探索者 / 阿波罗 STM32F4 开发板的实验项目合集，共 11 个独立 Keil MDK 工程，涵盖无线通信、波形输出、音频播放、存储读写、USB 主机等外设应用。

| 目录 | 开发板 | 功能说明 |
| --- | --- | --- |
| [001NRF24L01无线通信实验](001NRF24L01无线通信实验) | 阿波罗 F429 | NRF24L01 2.4G 无线模块收发通信实验 |
| [002NRF24L01无线发送角度](002NRF24L01无线发送角度) | 阿波罗 F429 | NRF24L01 2.4G 无线发送角度数据 |
| [002NRF24L01无线接受手柄数据-006](002NRF24L01无线接受手柄数据-006) | 阿波罗 F429 | NRF24L01 2.4G 无线接收手柄数据 |

## 开发环境

- 芯片：STM32F407ZGT6（探索者）/ STM32F429IGT6（阿波罗）
- 工具：Keil MDK-ARM
- 固件库：STM32 标准外设库 / HAL 库

## 使用说明

- 各工程相互独立，打开对应目录下 `USER/*.uvprojx` 工程文件即可编译下载
- 阿波罗 F429 工程与探索者 F407 工程引脚定义不同，请勿混用
- Keil 构建产物（OBJ、Listings、DebugConfig 等）已通过 `.gitignore` 排除，不纳入版本管理
