# stm32-ai-projects

基于正点原子探索者 V2（STM32F407ZGT6）开发板的实验项目合集，共 12 个独立 Keil MDK 工程，涵盖无线通信、波形输出、音频播放、存储读写、USB 主机等外设应用。

## 开发环境

- 开发板：正点原子探索者 V2（STM32F407ZGT6）
- 工具：Keil MDK-ARM
- 固件库：STM32 标准外设库 / HAL 库

## 使用说明

- 各工程相互独立，打开对应目录下 `USER/*.uvprojx` 工程文件即可编译下载
- 全部工程基于探索者 V2（F407），引脚定义一致，可直接在探索者 V2 开发板上运行
- Keil 构建产物（OBJ、Listings、DebugConfig 等）已通过 `.gitignore` 排除，不纳入版本管理
